# Панель финансовой устойчивости российских банков

Проект собирает **long-format unbalanced panel** с единицей наблюдения
`REGN_GKO × year` за 2007–2021 годы. Числовые значения берутся из официальных
индивидуальных файлов Банка России; для названия предусмотрен одноцелевой
запрос к `analizbankov.ru`, но при недоступности сайта используется официальный
реестр названий из архивов ЦБ (это не числовой показатель). Групповые нормативы
`Н20.x` отбрасываются.

## Быстрый запуск

```bash
python -m venv .venv
.venv/bin/pip install -e '.[dev]'
.venv/bin/python -m pytest
.venv/bin/python -m bank_panel.cli --raw-dir data/raw
.venv/bin/python -m bank_panel.translate_cli
```

Команда создаёт один лист `bank_year` в `data/processed/bank_panel_2007_2021.xlsx`
и совместимый с Gretl файл `data/processed/bank_panel_2007_2021.csv` (UTF‑8 BOM).
Русская версия с теми же числовыми значениями создаётся в той же папке как
`bank_panel_2007_2021_ru.xlsx` и `bank_panel_2007_2021_ru.csv`; переводятся
заголовки и текстовые единицы измерения, числовые ячейки не пересчитываются.
Добавление новых наблюдений выполняется через `bank_panel.export.append_rows`,
который заменяет дубликат по `(regn_gko, bank_name, year)` и сохраняет long format.

## Источники и ограничения

ЦБ публикует исторические архивы форм 101 (оборотная ведомость), 102 (ОФР),
123 (капитал) и 135 (индивидуальные нормативы) в DBF внутри ZIP/RAR на
странице [отчетности кредитных организаций](https://www.cbr.ru/banking_sector/otchetnost-kreditnykh-organizaciy/).
В архиве 135 таблица `*_135_3.DBF` содержит индивидуальные нормативы с кодом
`Н` (включая Н1.0, Н1.1, Н1.2, Н1.4, Н2, Н3, Н4, Н7, Н9.1, Н10.1, Н12,
Н15, Н16 и Н18); архив 0409805 намеренно не используется. Для 2007–2010,
когда архивы 135 отсутствуют на портале, реестр банков берётся из
индивидуального раздела формы 102, а нормативы остаются пропущенными. Для
формы 101 используются коды плана счетов ЦБ: капитал (102–109), денежные
средства (202), счета в Банке России (30102), межбанковские размещения
(320–323), кредитный портфель (441–459), кредиты юридическим лицам (441–454,
456), счета физических и юридических лиц, депозиты (410–440), ценные бумаги
(501–506), просроченная задолженность (458–459), государственные долговые
обязательства (50305–50306), резервы и обязательные резервы. В форме 102
учтены изменения нумерации ОФР: старые строки 10000/20000/31001/33001,
строки 01000/28101 и новые 10001–10004/61101. Значения берутся из готовых
строк ЦБ; арифметические разности и замены пропусков не выполняются. Для
формы 135 дополнительно выгружается строка высоколиквидных активов `Лам`.

Схема показателей и официальные названия находятся в
`config/indicators.yml`; новые коды/строки добавляются туда явно. Для каждого
значения предусмотрены колонки единицы измерения, формы, кода строки и URL
источника. Пустое значение означает отсутствие соответствующей строки в
официальном файле, а не рассчитанное или подставленное значение.

Исходные архивы `data/raw/` исключены из Git из-за размера. Текущие результаты
в `data/processed/` сохранены в репозитории для прямого скачивания; их можно
пересобрать после повторной загрузки архивов.
